把书读薄，把世界读厚。**薄书**将一本书提炼成适合连续阅读的短文，尽量保留故事脉络、核心论证与叙述气质。内置 **601 本好书、10 类书库**，支持系列查找、在线找书、原文导入、收藏、阅读进度与 Markdown 导出。

> 更推荐阅读原著：原著有更丰富的细节、语言与体验。未提供完整原文时，薄书会标记为「资料提炼」或「节选缩写」。

## 环境配置与安装

安装 [Node.js 最新版 24 LTS](https://nodejs.org/)（至少 24.5），下载项目后进入目录。首次启动需联网安装依赖。

| 系统 | 启动方式 |
| --- | --- |
| Windows | 双击 **`start.bat`**，自动安装依赖并打开浏览器 |
| Linux | 在项目目录执行 **`sh start.sh`**；桌面双击可使用 `ThinBook.desktop`，首次赋予执行权限并允许启动 |
| 终端 | `npm ci`，随后 `npm start` |

主机访问 **<http://127.0.0.1:3210>**。关闭启动终端即可停止服务。

## 快速使用

1. 在**主机本地页面**打开「模型设置」，填写自己的 DeepSeek API Key，测试并保存。Key 写入项目 `.local/config.json`，不再保存到浏览器；该目录已排除版本控制和 npm 打包。
2. 搜索或选择一本书，选择 **5 / 10 / 20 分钟**。输入系列名或点击书籍详情中的系列入口，可按顺序查看同系列书籍。有原文时可粘贴或导入 UTF-8 TXT / Markdown，再开始读薄。
3. 完成后自动缓存到 `.local/readings/`，页面以小字展示费用估算。相同书籍、篇幅、模型、原文和规则再次请求会优先使用缓存，**缓存读取不调用 API**。「最近阅读」可打开已有缓存。
4. 手机或平板连接同一局域网，打开主页展示的 `http://192.168.…:3210` 地址即可继续使用。其他设备共用主机配置与缓存；修改 Key 只允许在主机的 `127.0.0.1` 页面操作。

API 生成与联网取材会产生 DeepSeek 费用；页面金额为参考估算，实际以账户账单为准。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 首次安装失败 | 检查 Node.js 版本和网络，在项目目录重新执行 `npm ci` |
| `scope carrier` / Harness 启动错误 | 关闭旧启动窗口，执行 `npm ci` 或重新双击启动脚本；勿单独升级 Harness 或 SDK |
| 联网找书失败 | 已支持环境代理、代理连接失败后的直连重试与备用书库。检查代理端口是否仍有效；全部不可达时会明确返回本地匹配，仍可自选书名与作者 |
| 手机打不开页面 | 确认主机正在运行、设备处于同一局域网。Windows 防火墙需允许 Node.js 的专用网络入站连接，或仅在专用网络开放 TCP 3210；检查路由器是否开启客户端隔离 |
| 想只允许本机访问 | 设置环境变量 `HOST=127.0.0.1` 后启动 |
| Key 无效或余额不足 | 在主机设置中测试连接，确认 Key、模型权限及账户余额 |
| 想更换端口 | 设置环境变量 `PORT`（如 `3211`）后启动，以终端打印地址为准 |
| 未生成可靠正文 | 可补充原文或增加阅读时长；系统不会用虚构细节填补资料缺口 |

实现、缓存、费用计算和隐私细节见 [技术文档](docs/implementation.md)，系列范围与核对来源见 [书目说明](docs/catalog-series.md)。维护验证：`npm test`。
