# 系列书目与核对来源

核对日期：2026-10-16。书库现有 601 本，保留原有 429 本，新增 172 本。以下 40 组记录涵盖主系列、前传、外传、授权续作和主题套书；每本新增书均有原创简短介绍。

## 查找与顺序

在搜索框输入系列名即可查找；输入下表的完整系列名时，页面按清单顺序展示该组。书籍详情也提供系列入口和序号。通常采用出版顺序，例外在说明中写明；序号不代表故事内的时间。

同一作品的不同译名存为搜索别名，已收录的合集继续保留。新增卷册只含元数据，不附原文；原有 classic 编号保持不变，避免破坏收藏与阅读记录。

## 收录范围

以能核对的已出版主线为先，另外单列部分外传和授权续作。此表不代表穷尽所有共享宇宙、后世改编、衍生短篇或其他作者授权续写。中文译名不能可靠确认的近期或海外作品保留原文正式书名；中文别名仅便于检索，不表示存在对应的正式简体中文版。

《魔戒》《福尔摩斯探案全集》《平凡的世界》等原有完整作品不为增加数量拆成装订分册。《纳尼亚传奇》保留合集入口，同时补充七部可独立选读的小说。已齐的《三体》和《激流三部曲》保留原有书目。未出版的冰与火之歌后续卷不加入。主题三部曲与独立侦探案件不等同于剧情连续的续集。
