# 薄书：实现与数据说明

本文保存 README 之外的实现细节，面向维护者。使用入口见 [README](../README.md)。

## 架构与依赖

- 原生 Node.js HTTP 服务 + 无构建 HTML / CSS / JavaScript 前端。
- 官方 `@deepseek-ai/dsh` 与 `@deepseek-ai/dsh-sdk-client` 均固定为 `0.2.0-rc.2`；保持一致，避免不同副本的 scope 私有标记互不识别。
- `harness/reader.mjs` 通过 SDK 的 stdio JSON-RPC 驱动 `sdk-minimal`，每次生成使用独立环境和临时运行目录，支持取消与 12 分钟超时。
- `harness/reader.patch.yml` 仅开放 `web_search`、`web_fetch`、`skill`，关闭默认的命令执行工具。
- `.dsh/skills/thin-book/SKILL.md` 是可编辑的提炼契约，也会直接放入系统提示。小说保留主线因果、人物关系、转折与结局；非虚构保留命题、论证、代表案例及适用边界。
- `scripts/check-dependencies.mjs` 为双击启动流程检查直接依赖版本；不匹配时由启动脚本执行 `npm ci`。

## 本地配置与密钥

配置在用户第一次保存时创建，示意如下（不填入真实密钥）：

```json
{
  "apiKey": "YOUR_DEEPSEEK_API_KEY",
  "model": "deepseek-flash"
}
```

Key 仅由主机的 `http://127.0.0.1` 或 `http://localhost` 页面写入和测试。后端保存后只向网页返回 `hasKey` 和模型名称，从不读回原始 Key。留空保存保留当前 Key；「移除已保存的 Key」会清空配置中的 Key。

生成请求不携带 Key，由服务端读取配置、经独立子进程环境传给 DeepSeek 官方接口。测试连接使用固定官方地址。服务端不会把整个配置提供为静态文件，不将 Key 写入缓存、模型提示或错误日志。旧版浏览器 Key 在主机页面成功迁移后清除。

`.local/` 同时受 `.gitignore`、`.npmignore` 和 `.gitattributes export-ignore` 排除；正常 Git 提交、npm 打包和 Git archive 均不应包含它。分享项目时保留这些排除规则，不要手动打包 `.local`、`.runtime` 或 `.env`。配置是主机上的本地明文文件：POSIX 下采用目录 0700、文件 0600；Windows 下遵循当前目录的访问控制，不声称由 chmod 提供加密。用户自行强制提交、共享整个文件夹或移除排除规则仍可能造成泄露。

用户主动导入的原文会发送给 DeepSeek 进行提炼。临时会话可能包含该文本，正常完成或取消后清理；断电或强制结束进程可能留下 `.runtime` 残余。停止服务后可自行删除该目录。

## 缓存与阅读进度

每篇结果存为 `.local/readings/<sha256>.json`，通过临时文件加重命名写入，避免半截 JSON。缓存键包含书名、作者、模型、阅读时长、原文哈希、是否完整原文，以及 skill 内容哈希；Key 不参与计算，也不写入缓存。原文正文不作为单独缓存字段存储。

相同条件再次生成会直接返回缓存，不调用模型。变化条件会生成新版本。API 的 `force: true` 可跳过缓存，可能再次计费；页面默认复用缓存。磁盘写入失败会保留当前正文并提示导出，不能将其标为已成功缓存。

「最近阅读」启动时从项目缓存加载，其他局域网设备也可读取。书架、字号和阅读进度仍由各设备的浏览器保存，不跨设备同步。项目缓存是所有访问本服务的局域网设备共用的，不适用于相互不信任的访客。

## 用量与费用估算

核价快照：**2026-10-15**，单位 USD / 百万 token，来自 [DeepSeek 官方价格页](https://api-docs.deepseek.com/quick_start/pricing/)。

| 模型 | 峰时未命中输入 | 峰时缓存命中输入 | 峰时输出 |
| --- | ---: | ---: | ---: |
| `deepseek-flash` | 0.30 | 0.006 | 1.20 |
| `deepseek-v4-pro` | 1.32 | 0.044 | 3.96 |

`deepseek-v4-flash` 等官方兼容别名按 Flash 计算。低谷价格为峰时的一半。为避免将节假日、跨时段调用误当作精确账单，页面展示参考范围，并把价格快照日期存入缓存。

主会话使用 Harness 的 `assistant/message.usage`：未缓存输入、缓存命中输入和输出分别计算；推理 token 已计入输出，不重复相加。未知模型或缺少用量时显示「暂无可靠用量估算」，不返回虚假的零费用。

官方搜索插件会记录辅助模型请求，但当前不向本项目返回搜索用量。因此每次记录的搜索调用在费用参考范围中暂按约 1 万输入、4096 输出 token 的峰时费用加算；这个数字是估算假设，不是最大费用保证。服务端搜索上下文、失败或重试调用的额外费用可能超出范围，实际账单以 DeepSeek 为准。未来若插件提供搜索 usage，应替换为实测统计。

缓存保留原生成的费用估算，重新打开时另标「本次读取本地缓存 · API 费用 US$0」，不会把历史生成费用当作本次扣费。

## 联网搜索与代理

书目检索与读薄取材是两条流程：

1. 书目搜索优先使用 [Open Library Search API](https://openlibrary.org/dev/docs/api/search)，失败或无结果时尝试 Google Books。书目返回字段用于卡片与选书；没有简介时如实说明，不编造故事。
2. `lib/network.mjs` 显式使用 Undici 的环境代理，遵循 `HTTP_PROXY` / `HTTPS_PROXY` / `NO_PROXY` 及小写形式；代理连接失败时对公共书目源尝试直连，不关闭 HTTPS 证书验证。
3. 远程书库全部不可达时，明确降级到本地匹配，不把本地书目冒充联网结果，也不会缓存失败状态。成功搜索在内存中缓存 10 分钟。
4. 读薄取材由 Harness 官方 DeepSeek 搜索与抓取插件完成，使用主机 Key，独立计入 API 成本；子进程继承环境代理。

有代理时，将 `127.0.0.1,localhost` 加入 `NO_PROXY`，避免本机页面请求经过外部代理。程序不会自动修改系统代理或防火墙。

## 局域网访问

默认监听 `0.0.0.0:3210`。主页与启动终端展示实际网卡的私有 IPv4 URL；排序优先物理以太网和 `192.168.*` 地址，主展示排除 VMware、WSL 等虚拟网卡。可通过 `HOST=127.0.0.1` 切回仅本机模式，`PORT` 修改端口。

只接受回环与私有网段客户端、主机实际网卡地址对应的 Host，并检查请求来源及每次服务启动生成的写入 token，阻止无关网站的跨站请求。配置修改额外要求回环连接和 localhost Host；局域网客户端无法取回或更换 Key，但可以使用主机配置生成内容，因此会使用同一个账户的额度。局域网设备必须是可信使用者，不要进行公网端口映射。

Windows 防火墙的网络权限和路由器客户端隔离由用户的系统管理。项目不自动开放入站规则；需要时仅允许专用网络的 Node.js / TCP 3210。

## 内容与质量边界

没有原文时输出「资料提炼」，只覆盖实际检索资料；部分原文输出「节选缩写」；仅在用户确认完整原文时按完整原文缩写，仍须核对覆盖说明。目标时长按每分钟约 350 汉字计算，不承诺短文与全书信息等价。

正文是连续短文，尽量保留人称、节奏与气质，采用自己的表达，不拼贴大段原文。读薄后仍推荐阅读原著。输出来源会与成功的 Harness 工具记录中的结构化 URL 交叉核验；未提供原文时至少需要两个不同来源和成功搜索记录。该检查不等于已经验证每个事实或每条论据。

## 维护验证

`npm test` 包含书库与简介完整性、输入边界、引用证据、磁盘持久化与缓存命中、费用计算、备用搜索、局域网权限，以及真实 Harness 的离线会话回归。

`node scripts/check-harness.mjs` 使用只在检查脚本中加载的测试模型流，运行官方 Harness 的会话创建、提示与工具组装、流式回复和结果解析，不访问外部 API。不能把它当作真实付费模型质量验证。

维护页面可执行 `npm run dev`；项目不依赖前端构建。更新依赖后同时运行上述测试，确认 SDK 和 Harness 的版本没有分叉。真实生成与搜索质量还需用户配置有效 Key 后验证。
